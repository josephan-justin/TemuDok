# 🩺 TemuDok

TemuDok adalah aplikasi web untuk melakukan booking konsultasi dokter secara online. Aplikasi ini dibangun menggunakan Node.js, Express.js, PostgreSQL, Sequelize, dan EJS dengan arsitektur MVC.

## ✨ Features

- User Registration & Login
- Session Authentication
- Profile Management
- Doctor Recommendation
- Search Doctor by Specialization
- Book Appointment
- Reschedule Appointment
- Cancel Appointment
- Email Notification (Nodemailer)
- Admin & Doctor Dashboard

## 🚀 Installation

Clone repository

```bash
git clone https://github.com/josephan-justin/TemuDok.git
```

Install dependencies

```bash
npm install
```

Create database

```bash
npx sequelize db:create
```

Run migrations

```bash
npx sequelize db:migrate
```

Run seeders

```bash
npx sequelize db:seed:all
```

Start application

```bash
npm start
```
